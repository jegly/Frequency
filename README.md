##  About this Fork
**Tunes** is a modified version of the open-source **Pulse Music** application. While it retains the beautiful core UI and features of the original, this fork introduces specific bug fixes and UI adjustments to improve the user experience.

### Key Changes & Fixes (vs. Original):
- **Playlist Stability:** Fixed a critical bug where adding songs to a newly created playlist would cause a crash until an app restart.
- **Search UI Fixes:** Resolved build and runtime errors related to private resource access in the `SearchView` (search plate background).
- **Theme Optimization:** Streamlined resource definitions to prevent duplicate style errors (e.g., Purple accent conflicts).
- **Dependency Updates:** Updated internal logic to ensure compatibility with modern AndroidX libraries and private resource restrictions.
